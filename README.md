# 错题收集工作台

纯静态网站，帮学生收集、复习错题。数据存在浏览器本地（不上传到服务器）。

## 功能
- 添加错题：科目、题目（文字或图片）、错误答案、正确答案、解析、错因、知识点
- 筛选与搜索
- 复习模式：按科目抽题，答对 3 次算掌握
- 统计：按科目、按错因分布
- 导出 / 导入 JSON，可在设备间迁移数据

## 本地开发
```
npm install
npm run dev      # 开发服务器
npm test         # 跑测试
npm run build    # 产出到 dist/，用于部署
```

## 部署
GitHub Actions 在合并到 `main` 后自动构建并部署到 AWS（S3 + CloudFront）。
